💡 Tips & Best Practices
📸 Document Quality

Use scans at 300dpi or higher. Ensure the MRZ (bottom two lines of passport) is fully visible and not cropped. Avoid glare and shadows.

🪪 MAECI Card Priority

When available, upload the MAECI card. As a printed ID from controlled sources, it gives the most accurate title and name extraction.

🔄 Reset Between Letters

Use the Reset button after each letter to clear all data. The Word template remains loaded — only document data and mission fields are cleared.

✏️ Manual Corrections

All extracted fields are editable. Click any value to correct it directly in the card. Changes apply immediately to the generated document.

🔒
Security & Data Privacy

All document processing occurs locally in your browser. No personal data is transmitted to external servers. The session auto-locks after 5 minutes of inactivity. All document data is cleared from memory when the page is closed. The access password is stored as a SHA-256 hash and cannot be recovered.

Complete all mission fields. These are inserted directly into the Nota Verbale text:

Protocol Number — e.g. VR/346/26. The VR/ prefix is added automatically if omitted.
Embassy Destination Country — the country whose embassy will receive the note. Type to search.
Nationality — adjective form (e.g. Italian, Brazilian). Add a 2nd nationality with the + 2nd nationality button.
Signing Date — the date Rome signs the note.
Departure / Return Date — the mission travel window.
Mission Purpose — e.g. attend the Eighth Global Environment Facility Assembly. Do not include "to" at the start — it is already in the template.
ℹ️ All fields except the document upload are required to generate the Nota Verbale.

💡 Tips & Best Practices
📋 Protocol Number Format

Enter the full protocol number including the VR/ prefix (e.g. VR/346/26). If you omit it, the system adds it automatically. Do not type it twice.

🌍 Dual Nationality

If the staff member holds two passports, click + 2nd nationality to add it. The output will read British and Irish automatically.

✍️ Mission Purpose Wording

The template already includes the word "to" before the purpose. Start your entry with the verb: attend the…, participate in…, represent IFAD at…

🔄 Reset Between Notes

Use the Reset button to clear all fields between Nota Verbale. The template file stays loaded so you only need to reload it when starting a new session.

🔒
Security & Data Privacy

All processing is local — no data leaves your browser. The session auto-locks after 5 minutes of inactivity. All document data is erased when the page is closed.
